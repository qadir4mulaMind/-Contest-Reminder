# 🏆 Contest Reminder

A Progressive Web App (PWA) that shows upcoming DSA contests from all major platforms — Codeforces, LeetCode, CodeChef, AtCoder, HackerRank, HackerEarth, TopCoder, and Toph — all in one place.

## ✨ Features

- 📅 **All contests in one place** — 8+ platforms aggregated
- 🕐 **IST timezone** — times shown in India Standard Time
- 🔴 **Live status** — see which contests are currently running
- 📱 **Installable PWA** — works like a native app
- ⚡ **Offline support** — service worker caches the UI
- 🎨 **Dark mode UI** — easy on the eyes
- 🔄 **Auto-refresh** — updates every 5 minutes

## 🛠️ Tech Stack

**Backend:**
- Python 3
- FastAPI
- Uvicorn
- Requests

**Frontend:**
- Vanilla HTML / CSS / JavaScript
- PWA (manifest + service worker)

**Data Source:**
- [Contest Hive API](https://contest-hive.vercel.app/)
